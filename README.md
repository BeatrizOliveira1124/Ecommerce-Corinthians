# Orgulho Timão

Bem-vindo ao repositório do **Orgulho Timão**, um site dedicado aos torcedores do Sport Club Corinthians Paulista. Este projeto celebra a paixão pelo Timão, oferecendo produtos oficiais, informações e uma experiência única para a Fiel Torcida.

## 📋 Descrição

O site **Orgulho Timão** foi desenvolvido para proporcionar aos torcedores uma plataforma onde podem explorar e adquirir produtos oficiais do Corinthians, além de conhecer mais sobre a história e cultura do clube. O projeto é responsivo e otimizado para diferentes dispositivos, garantindo uma navegação fluida.

## 📂 Estrutura do Projeto

Abaixo está a estrutura organizada do projeto:

### Arquivos Principais
- **`index.html`**: Página inicial do site.
- **`produtos.html`**: Página de listagem de produtos.
- **`detalhes-produtos.html`**: Página com detalhes de um produto específico.
- **`carrinho.html`**: Página para gerenciar o carrinho de compras.
- **`login.html`**: Página de login e cadastro de usuários.
- **`contatos.html`**: Página de contato com formulário.
- **`sobre.html`**: Página com informações sobre o projeto.

### Diretórios
- **`CSS/`**: Contém os arquivos de estilo do site.
  - `style.css`: Estilo principal do site.
  - `carrinho.css`: Estilo específico para a página do carrinho.
  - `contatos.css`: Estilo específico para a página de contato.
  - `detalhes-produtos.css`: Estilo específico para a página de detalhes do produto.
  - `login.css`: Estilo específico para a página de login.
  - `produtos.css`: Estilo específico para a página de produtos.
  - `sobre.css`: Estilo específico para a página sobre o projeto.

- **`IMAGENS/`**: Contém todas as imagens utilizadas no site, como logotipos, banners e fotos de produtos.

- **`JS/`**: Contém os scripts JavaScript do site.
  - `script.js`: Script principal para funcionalidades interativas.

## 🚀 Funcionalidades

- **Página Inicial**: Destaques de produtos e informações sobre o Corinthians.
- **Produtos**: Listagem de produtos oficiais com preços e avaliações.
- **Detalhes do Produto**: Informações detalhadas sobre cada item.
- **Carrinho de Compras**: Adicione e gerencie produtos no carrinho.
- **Login e Cadastro**: Sistema de autenticação para usuários.
- **Contato**: Formulário para envio de mensagens.
- **Sobre Nós**: Informações sobre a missão e visão do projeto.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura do site.
- **CSS3**: Estilização e design responsivo.
- **JavaScript**: Funcionalidades interativas.
- **Font Awesome**: Ícones para navegação e avaliações.

## 📱 Responsividade

O site foi projetado para ser responsivo e adaptável a diferentes dispositivos, incluindo desktops, tablets e smartphones. Foram utilizados media queries no CSS para ajustar o layout conforme o tamanho da tela.
